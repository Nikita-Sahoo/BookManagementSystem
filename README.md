#Online Library System

A React + Redux Toolkit web application to manage books. Users can browse, search, filter by category, view details, and add new books.

🚀 Features

1. Browse all books
2. Search by title or author
3. Filter by category
4. View book details
5. Add new books
6. Custom 404 page
7. State management using Redux Toolkit

🛠 Tech Stack
    React (Vite)
    Redux Toolkit
    React Router DOM
    Tailwind CSS


Installation Process
    Clone the Repository
        git clone https://github.com/your-username/book-management-system.git
    2️⃣ Navigate to Project Folder
        cd book-management-system
    3️⃣ Install Dependencies
        npm install
    4️⃣ Start Development Server
        npm run dev
    5️⃣ Open in Browser
        http://localhost:5173
